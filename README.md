# 📚 Banco de Dados - UC

Repositório contendo a resolução das atividades desenvolvidas para a Unidade Curricular (UC) de **Banco de Dados**, ministrada pelo **Professor Robson Calvetti**, na **Universidade São Judas Tadeu – Campus Butantã**, período **noturno**.

## 🎯 Objetivo

Este repositório tem como objetivo armazenar e organizar as atividades propostas durante a disciplina, servindo como material de estudo, consulta e acompanhamento da evolução dos conteúdos abordados.

## 📂 Atividades

| Atividade | Tema | Conteúdo |
|---|---|---|
| [`01_Atividade.md`](01_Atividade.md) | T01 — Fundamentos de Bancos de Dados | Diferenças entre dado, informação e metadado; redundância e inconsistência de dados; papel do SGBD, do cliente (Workbench) e do mecanismo de armazenamento (InnoDB); modelagem inicial de entidades e relacionamentos; controle de acesso e privilégio mínimo. |
| [`02_Atividade/`](02_Atividade) | T02 — Modelização Conceitual: Entidades e Atributos | Níveis de modelagem (conceitual, lógico, físico); distinção entre entidades e atributos; tipos de atributos (simples, compostos, multivalorados, derivados); identificadores naturais x substitutos; entidades fracas e chaves parciais; correção de modelos de dados. |
| [`03_Atividade/`](03_Atividade) | T03 — Relacionamentos e Restrições | Tipos de relacionamento (binário, ternário, recursivo); cardinalidades mínima e máxima; relacionamentos autorreferentes com nomeação de papéis; promoção de relacionamentos N:N para entidades associativas; validação e correção de um DER completo. |

## 🛠️ Tecnologias e Conceitos

- Modelagem conceitual de dados (DER)
- SGBD MySQL / MySQL Workbench
- Fundamentos de integridade referencial e controle de acesso
