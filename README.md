# 📚 Banco de Dados - UC

Repositório contendo a resolução das atividades desenvolvidas para a Unidade Curricular (UC) de **Banco de Dados**, ministrada pelo **Professor Robson Calvetti**, na **Universidade São Judas Tadeu – Campus Butantã**, período **noturno**.

## 🎯 Objetivo

Este repositório tem como objetivo armazenar e organizar as atividades propostas durante a disciplina, servindo como material de estudo, consulta e acompanhamento da evolução dos conteúdos abordados.
